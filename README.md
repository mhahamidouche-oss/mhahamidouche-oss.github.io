# Analyse discriminante

Application d'analyse discriminante (procédure DISCRIMINANT de SPSS) pour téléphone, tablette et PC.
Elle fonctionne sans Internet une fois installée. Les calculs se font sur l'appareil : aucune donnée n'est envoyée.

Langues : français, arabe, anglais.
Formats lus : .sav, .xlsx, .xls, .ods, .csv. Export des résultats : Word (.docx) et PDF.
